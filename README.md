# Бизнес-аналитика - Панель управления

SPA приложение для мониторинга бизнес-показателей.

## 🚀 Функциональность

- 📊 **Дашборд** - основные метрики и графики продаж
- 📋 **Отчеты** - генерация и просмотр отчетов
- 🔮 **Прогнозы** - аналитика и предсказания
- 📤 **Загрузка данных** - импорт данных
- ⚙️ **Настройки** - конфигурация системы

## 🛠 Технологии

- React 18
- React Router 6
- CSS-in-JS
- SVG графики

## 📦 Установка и запуск

```bash
# Клонирование репозитория
git clone <repository-url>
cd analytics-platform-frontend

# Установка зависимостей
npm install

# Запуск в development режиме
npm start
